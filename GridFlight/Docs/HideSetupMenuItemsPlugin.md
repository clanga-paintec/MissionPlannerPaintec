# HideSetupMenuItemsPlugin

**Archivo:** `GridFlight/HideSetupMenuItemsPlugin.cs`
**Perfil:** Solo Piloto
**Fase:** `Init()` (ejecucion unica)

## Que hace

Oculta items avanzados del menu **Mandatory Hardware** en Setup que no son relevantes para pilotos.

### Flags desactivados (3)

| Flag | Descripcion |
|------|-------------|
| `displayFailSafe` | Configuracion de failsafe |
| `displayHWIDs` | IDs de hardware |
| `displayADSB` | Configuracion ADS-B |
